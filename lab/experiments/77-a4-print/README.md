# 77: the book at A4, for a London print shop

The editor, 5 November 2026, about 14:02 UTC (brief 52): keep the Crown Quarto release (v0.1.1025) for KDP and Leanpub; for the London print shop, a print-ready A4 interior and A4 cover, formatted here rather than converted by the shop ("He says he converted, but it was a bit off").

- **a4.css**: read by publishing/build_book.py as extra CSS over the full book's own list. The Crown Quarto book is enlarged by 210/189 so its measure fills the A4 width (type, drawings and margins with it); A4's extra height becomes more lines a page, not blank space. The title page is centred on its cream ground. Built: 118 pages at A4 in the release (116 locally; the release's fonts set a little longer) (the Crown Quarto print interior is 123), the opening spread still facing on pages 2 and 3, pages more than 35% blank at the foot about the same as Crown Quarto (20 against 21).
- **make_a4_cover.py**: LAB 44's cover laid flat at A4: back + spine + front, 3 mm bleed. The front is cover A drawn to A4's shape (cover_signed(height)) and enlarged, so nothing is stretched; the back is LAB 44's back enlarged with its author line at the foot; the spine at its real width (6.75 mm for 118 pages, KDP's white-paper rule; rerun with --spine-mm for the shop's own width). a4-full-cover.pdf is 432.6 x 303 mm.
- **a4-interior.pdf**: the A4 interior as built in the conductor's session (106 pages, the book's own fonts embedded), kept as a file: the release copies it and the cover to rc2/upload/ instead of rebuilding them, since the release's fallback fonts set the book 11 pages longer and undid the fit.
