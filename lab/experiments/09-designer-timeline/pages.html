How a page uses it

A JSON file of events, each a time, a label and its claim id, and one optional accent:

{"t": "18:44",
 "label": "The hold",
 "claim": "C006",
 "accent": true}

On a lab page, one line places it:

{{​timeline:<spec>:horizontal:163}}

From the command line, the same SVG for the book or the site:

python3 lab/tools/components/
  timeline.py spec.json vertical 110

Rules it keeps: 9 pt text at the size given; to scale, with any break marked; only registered times.
