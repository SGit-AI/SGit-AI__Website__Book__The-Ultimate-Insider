# LAB 45: the Try this card

One card per chapter, the same design in all of them, in place of "Do this now" (conductor 060; the storyteller's 118; the
cast guide's page conventions, item 1). The design is CSS, `lab/tools/book/try-this.css`, so the publisher's build sets
it from the chapter's own words; its header comment gives the markup. The chapter's "## Try this" section gives three
paragraphs, in order: the idea (one line), what I would try first (his invitation), what it gives you (one line).
pages.html shows it at the book's size with sample words; the writer's lines replace them.
