# Review: Leanpub added as a collaborator on this repository

Leanpub's Git and GitHub writing mode needs the editor to add the GitHub account `leanpub` as a collaborator on this repository (step 2 of `publishing/LEANPUB.md`). That is the first outside account with access to it. Please say, before the editor does it, what it can reach (read only, or write?), whether anything in the repository should not be read by it, and whether it belongs in your control register. Nothing secret is in the repository by rule, so I expect "fine, record it"; it is your call, not mine.
