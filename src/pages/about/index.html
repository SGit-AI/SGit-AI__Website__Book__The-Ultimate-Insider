About this site

The working site of the book of The ultimate insider, a talk by Dinis Cruz at hack::soho, IOActive London, on 29 October 2026. The book is written in public: the plan, the team, the decisions and the manuscript are published here as they change.

A disclosure

This site is published by the editor of the book, who also gave the talk, and the projects the talk points to (sgit.ai among them) are ones he founded or works on. Most of the writing is done by AI agents working for him, under the rules in the rules for agents.

How it is built

The same way as the talk's site, cut to what the book needs on day one: a Python build with the standard library only (admin/build/build.py), pages written as fragments in src/pages/, the book's plan as data in book.json, the briefs in briefs/, and the manuscript in manuscript/, in the order Leanpub reads it from manuscript/Book.txt. Every page has a markdown twin at the same path, and llms.txt lists them all.

How it is released

CI owns the version. Every push is built with the version "pending" and gated. A push to dev or main then gets one release: CI reads the newest tag, picks the next number (dev bumps the last number, main the middle one), commits it to ./version, tags that commit, builds it, gates it again, deploys it to GitHub Pages and checks the live site serves it. Nobody else writes the version. Every release is in the release history.

What the gate checks

  • every link inside the site resolves, and every page is linked from another;
  • every page has its markdown twin and is listed in llms.txt;
  • every page carries structured data and the build's version in its top bar;
  • no {{ placeholder survives the build;
  • no script or stylesheet loads from another host;
  • every script parses;
  • book.json has what the pages need, and every file in manuscript/Book.txt exists;
  • no em-dashes in prose;
  • the leak tripwire: nothing that looks like a key or a token, in any tracked file or in the built site.

What it does not claim

The numbers on this site come from the editor's brief and have not yet been re-checked by the book's researcher. Until a number is in the researcher's register, it is the brief's, not the book's.
